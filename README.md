# EnzyWizard-Disorder

EnzyWizard-Disorder is a command-line tool for predicting intrinsically
disordered regions from a cleaned protein structure and generating a detailed
JSON report. It extracts the protein sequence from the cleaned structure and
applies a FoldIndex-like disorder prediction algorithm based on residue
hydrophobicity and net charge. The program identifies continuous residue
segments with disorder-prone physicochemical signatures and summarizes both
disordered region predictions and disordered region statistics across the protein.

# example usage:

The examples below use placeholder paths such as `path/to/input.cif` and
`path/to/output_dir/`; replace them with your own cleaned input structure file
and output directory.

Predict disordered regions from a cleaned CIF file with default settings.
The default sliding window size is 11 residues, and the default minimum
reported region length is 5 residues.

```
enzywizard-disorder -i path/to/input.cif -o path/to/output_dir/
```

Predict disordered regions from a cleaned PDB file with default settings.

```
enzywizard-disorder -i path/to/input.pdb -o path/to/output_dir/
```

Predict disordered regions using long option names.

```
enzywizard-disorder --input_path path/to/input.cif --output_dir path/to/output_dir/
```

Use a smaller sliding window to make the disorder scores more sensitive to
local sequence fluctuations. This can detect shorter local disorder-prone
patterns, but the predictions may be less smooth. The `--window_size` value
must be an odd integer from 3 to 50.

```
enzywizard-disorder -i path/to/input.cif -o path/to/output_dir/ --window_size 5
```

Use a larger sliding window to smooth the disorder scores across a broader
sequence neighborhood. This emphasizes broad regional disorder tendencies, but
may reduce sensitivity to short local fluctuations. The `--window_size` value
must be an odd integer from 3 to 50.

```
enzywizard-disorder -i path/to/input.cif -o path/to/output_dir/ --window_size 21
```

Report only longer continuous disordered regions by increasing the minimum
region length. Short predicted segments below this threshold are filtered out.

```
enzywizard-disorder -i path/to/input.cif -o path/to/output_dir/ --min_region_length 10
```

Combine a larger smoothing window with a longer minimum region length to focus
on broad, persistent disordered regions. The `--window_size` value must be an
odd integer from 3 to 50, and `--min_region_length` must not be greater than
`--window_size`.

```
enzywizard-disorder -i path/to/input.cif -o path/to/output_dir/ --window_size 21 --min_region_length 10
```



# input parameters:

-i, --input_path
Required.
Path to the input cleaned protein structure file in CIF or PDB format.
Supported file extensions: .cif, .pdb.

-o, --output_dir
Required.
Path to the output directory for saving the JSON report.
The output directory is created automatically if it does not exist.

--window_size
Optional.
Sliding window size for disorder score calculation.
Default: 11.
Must be an odd integer from 3 to 50.
This parameter controls how many neighboring residues are used when averaging
hydrophobicity and net charge along the sequence. Larger values produce smoother
regional trends and emphasize broad disorder tendencies, while smaller values
are more sensitive to local sequence fluctuations.

--min_region_length
Optional.
Minimum number of consecutive residues required to define a disordered region.
Default: 5.
Must be an integer from 3 to 50 and must not be greater than --window_size.
Only continuous residue segments whose predicted disorder scores remain below
zero and whose lengths are at least this threshold are reported as disordered
regions.


# output files:

The program outputs the following files into the output directory:

`{name}` is derived from the input file name without its extension.

1. A JSON report
   - disorder_report_{name}.json
     - JSON report containing predicted disordered regions and disordered region statistics.

2. A log file
   - log.txt
     - Processing log containing informational messages and errors.


# output report schema:

The JSON report contains the following fields:

   - "report_type"
     - Data type: string
     - Expected value: "enzywizard_disorder"
     - Description: The field 'report_type' indicates the type of report ('report': http://purl.obolibrary.org/obo/IAO_0000088) generated by the EnzyWizard-Disorder software.

   - "disordered_region_statistics"
     - Data type: object
     - Description: The field 'disordered_region_statistics' indicates the summary statistics ('statistics': http://purl.obolibrary.org/obo/STATO_0000039) of intrinsically disordered regions ('intrinsically disordered region': https://disprot.org/ontology) calculated from the protein structure ('protein structure': http://edamontology.org/data_1537).

     The "disordered_region_statistics" object contains:

     - "disordered_region_count"
       - Data type: integer
       - Description: The field 'disordered_region_count' indicates the count of intrinsically disordered regions ('intrinsically disordered region': https://disprot.org/ontology).

     - "max_disordered_region_length"
       - Data type: integer
       - Description: The field 'max_disordered_region_length' indicates the maximum sequence length ('sequence length': http://edamontology.org/data_1249) of intrinsically disordered regions ('intrinsically disordered region': https://disprot.org/ontology).

     - "total_disordered_region_length"
       - Data type: integer
       - Description: The field 'total_disordered_region_length' indicates the total sequence length ('sequence length': http://edamontology.org/data_1249) of intrinsically disordered regions ('intrinsically disordered region': https://disprot.org/ontology).

   - "disordered_regions"
     - Data type: array
     - Description: The field 'disordered_regions' indicates intrinsically disordered regions ('intrinsically disordered region': https://disprot.org/ontology) in the protein structure ('protein structure': http://edamontology.org/data_1537).

     Each item in "disordered_regions" is an object containing:

     - "disordered_region_length"
       - Data type: integer
       - Description: The field 'disordered_region_length' indicates the sequence length ('sequence length': http://edamontology.org/data_1249) of the intrinsically disordered region ('intrinsically disordered region': https://disprot.org/ontology).

     - "residues"
       - Data type: array
       - Description: The field 'residues' indicates the residues ('residue': http://purl.obolibrary.org/obo/GENO_0000782) included in the intrinsically disordered region ('intrinsically disordered region': https://disprot.org/ontology).

       Each item in "residues" is an object containing:

       - "residue_index"
         - Data type: integer
         - Description: The field 'residue_index' indicates the index ('index': http://purl.obolibrary.org/obo/NCIT_C25390) of the residue ('residue': http://purl.obolibrary.org/obo/GENO_0000782).

       - "residue_name"
         - Data type: string
         - Allowed values: A, C, D, E, F, G, H, I, K, L, M, N, P, Q, R, S, T, V, W, Y.
         - Description: The field 'residue_name' indicates the name of the residue ('residue': http://purl.obolibrary.org/obo/GENO_0000782), using one-letter code ('one-letter code': https://iupac.qmul.ac.uk/AminoAcid/A2021.html) to represent.


# Process:

This command processes the input cleaned protein structure as follows:

1. Load the input structure
   - Read the cleaned CIF or PDB file using Biopython (Bio.PDB).
   - Resolve the protein name from the input filename.

2. Validate basic input conditions
   - Check that the input file exists.
   - Validate that the input structure satisfies the cleaned-structure requirement.

3. Extract sequence information
   - Extract the single chain from the cleaned structure.
   - Retrieve residues in chain order from the cleaned protein structure.
   - Confirm consistency between chain length and residue list length.
   - Convert residue names into a normalized one-letter amino acid sequence.

4. Predict residue-level disorder propensity
   - Assign each residue a predefined hydrophobicity value and net charge value.
   - Apply a sliding-window moving average to hydrophobicity and net charge
     along the sequence.
   - Calculate a FoldIndex-like score for each residue using:

       score = 2.785 × <mean hydrophobicity> - |<mean net charge>| - 1.151

   - Interpret the score as follows:
     - score < 0: predicted disorder-prone residue
     - score >= 0: predicted ordered residue

   - This algorithm is based on the principle that intrinsically disordered
     protein regions tend to have relatively low hydrophobicity and relatively
     high net charge. Lower hydrophobicity weakens the driving force for stable
     compact folding, while higher net charge increases electrostatic repulsion,
     both of which favor structural disorder.

5. Build disordered regions
   - Scan the residue-level FoldIndex-like scores in sequence order.
   - Merge consecutive residues with scores below zero into continuous
     candidate disordered segments.
   - Remove segments shorter than the user-defined minimum region length.
   - Record the residue composition of each retained disordered region.
   - Sort predicted regions by descending disordered region length.

6. Compute disordered region statistics
   - Count the total number of predicted disordered regions.
   - Calculate the maximum predicted disordered region length.
   - Calculate the total number of residues covered by predicted disordered regions.

7. Save outputs
   - Generate and save a JSON report containing both predicted disordered
     regions and disordered region statistics.


# common errors and solutions:

- "Invalid window_size"
  - Cause: The value passed to `--window_size` is outside the valid range or is an even integer.
  - Solution: Use an odd integer from 3 to 50, such as `5`, `11`, or `21`.

- "Invalid min_region_length"
  - Cause: The value passed to `--min_region_length` is outside the valid range or is greater than `--window_size`.
  - Solution: Use an integer from 3 to 50 and make sure it is not greater than `--window_size`.

- "Input not found"
  - Cause: The path passed to `-i` or `--input_path` does not exist or is not a file.
  - Solution: Check the input file path and make sure it points to an existing cleaned CIF or PDB file.

- "Unsupported format"
  - Cause: The input file extension is not `.cif` or `.pdb`.
  - Solution: Use a supported cleaned structure file format.

- "Exception in loading structure"
  - Cause: Biopython could not parse the input file as a usable protein structure.
  - Solution: Check that the file is valid, non-empty, non-corrupted, and matches its extension.

- "Structure must contain exactly one model. Please run 'enzywizard clean' first."
  - Cause: The input structure contains multiple models or no usable model.
  - Solution: Run the structure through `enzywizard-clean` first and use the cleaned output file.

- "Structure must contain exactly one chain. Please run 'enzywizard clean' first."
  - Cause: The input structure contains multiple chains or no usable chain.
  - Solution: Run the structure through `enzywizard-clean` first so it is converted to a single cleaned chain.

- "Cleaned structure must use chain ID 'A'. Please run 'enzywizard clean' first."
  - Cause: The input file is not in the cleaned single-chain format expected by EnzyWizard-Disorder.
  - Solution: Use a cleaned output file generated by `enzywizard-clean`.

- "Non-standard residue"
  - Cause: The input structure contains non-standard residues that were not converted to standard amino acid residues.
  - Solution: Run `enzywizard-clean` first and use its cleaned CIF or PDB output as the input.

- "Residue numbering is not continuous"
  - Cause: The cleaned input structure does not have continuous residue numbering starting from 1.
  - Solution: Run `enzywizard-clean` first and use the cleaned output file with continuous residue numbering.

- "missing CA atom"
  - Cause: A protein residue is missing its alpha carbon atom, so the sequence and residue list cannot be used reliably.
  - Solution: Check the structure quality and run `enzywizard-clean` before disorder prediction.

- "Failed to calculate intrinsically disordered regions"
  - Cause: Sequence extraction, residue validation, score calculation, or region construction failed.
  - Solution: Review earlier messages in `log.txt`, then check that the input is a cleaned single-chain protein structure with standard residues.

- Output files are missing
  - Cause: The command failed before the JSON report was written, or the output directory is not the one expected.
  - Solution: Check `log.txt`, confirm the `-o` output directory, and rerun after fixing earlier errors.

- Output file names are different from expected
  - Cause: Output names use `{name}`, which is derived from the input file name without its extension.
  - Solution: Check the input file name and look for `disorder_report_{name}.json` and `log.txt` in the output directory.
